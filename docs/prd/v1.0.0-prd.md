## 1. 项目概述

### 1.1 项目背景
打造一个关于"狼王格林"的个人主页网站，展示格林的生平、家庭、趣事，并提供互动识别功能。

### 1.2 项目目标
- 全面展示狼王格林的个人信息
- 提供沉浸式的视觉体验
- 增强用户互动性
- 支持多媒体内容（图片、视频）

## 3. 功能需求

### 3.1 页面结构

#### 页面1: 首页/基本信息
- **路由**: `/`
- **功能**:
  - 展示狼王格林的头像/大图
  - 基本信息卡片（姓名、别名、物种、出生地、特征等）
  - 导航菜单（指向其他页面）
- **设计要点**:
  - 响应式布局
  - 大气的视觉效果
  - 平滑滚动动画

#### 页面2: 家庭情况
- **路由**: `/family`
- **功能**:
  - 家庭成员介绍（父母、兄弟姐妹、伴侣、后代）
  - 家族树状图展示（可选）
  - 每个成员的简介和图片
- **设计要点**:
  - 卡片式布局
  - 成员关系可视化

#### 页面3: 有趣故事
- **路由**: `/stories`
- **功能**:
  - 故事列表展示
  - 每个故事包含：标题、时间、内容、配图
  - 点击展开查看详情
  - 按时间线排序
- **设计要点**:
  - 时间轴布局
  - 图文并茂
  - 支持折叠/展开

#### 页面4: 互动识别游戏
- **路由**: `/game`
- **功能**:
  - 展示多张狼的图片（3-6张）
  - 用户点击选择哪张是格林
  - 点击后显示答案反馈
  - 答对后跳转到对应的视频介绍
  - 支持重新挑战
- **交互流程**:
  ```
  1. 页面加载 -> 显示图片网格 + 提示文字
  2. 用户点击图片 -> 显示答案（正确/错误）
  3. 如果正确 -> 显示视频播放器（外部链接）
  4. 提供"再玩一次"按钮
  ```

## 5. 视频集成方案

### 5.1 B站视频嵌入
使用iframe嵌入B站视频：
```html
<iframe
  src="//player.bilibili.com/player.html?bvid=BV号"
  scrolling="no"
  border="0"
  frameborder="no"
  framespacing="0"
  allowfullscreen="true"
  width="800"
  height="600">
</iframe>
```

### 5.2 YouTube视频嵌入
```html
<iframe
  width="800"
  height="600"
  src="https://www.youtube.com/embed/视频ID"
  frameborder="0"
  allow="accelerometer; autoplay; clipboard-write; encrypted-media; gyroscope; picture-in-picture"
  allowfullscreen>
</iframe>
```
