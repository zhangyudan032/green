## 1. 项目概述

### 1.1 版本目标
v2.0.0是对v1.0.0的重大架构调整和体验优化，主要目标：
- **架构重构**：从多页面应用改为单页面应用（Single Page）
- **交互升级**：添加丰富的动效和交互体验
- **模块化设计**：采用模块化内容展示方式
- **视觉优化**：提升整体美观度和现代感

### 1.2 核心变更
| 变更项 | v1.0.0 | v2.0.0 |
|-------|--------|--------|
| 页面结构 | 多页面路由 (`/`, `/family`, `/stories`, `/game`) | 单页面滚动式布局 |
| 导航方式 | 页面跳转 | 锚点滚动 |
| 交互效果 | 基础点击 | 悬浮渐变、动态展示、平滑滚动 |
| 内容组织 | 分页展示 | 模块化区块展示 |
| 链接方式 | 静态文本 | 可点击跳转（网页/视频） |

## 3. 页面设计

### 3.1 整体布局结构

单页面由以下**垂直滚动区块**组成：

```
┌─────────────────────────────────────┐
│  Header（固定导航栏）                  │
├─────────────────────────────────────┤
│  Hero Section（主视觉区）             │
│  - 大图背景 + 标题                     │
├─────────────────────────────────────┤
│  About Section（基本信息区）           │
│  - 格林的详细介绍                      │
├─────────────────────────────────────┤
│  Family Section（家庭成员区）          │
│  - 卡片式展示                         │
├─────────────────────────────────────┤
│  Stories Section（故事展示区）         │
│  - 时间轴或网格布局                    │
├─────────────────────────────────────┤
│  Game Section（互动游戏区）            │
│  - 识别格林小游戏                      │
├─────────────────────────────────────┤
│  Footer（底部信息）                    │
└─────────────────────────────────────┘
```

### 3.2 区块详细设计

#### 3.2.1 Header - 顶部导航栏
**功能**:
- 固定在顶部（sticky）
- 导航链接（点击滚动到对应区块）
- 响应式设计（移动端收起为汉堡菜单）

**设计要点**:
- 半透明背景（backdrop-blur效果）
- 当前区块高亮显示
- 平滑滚动动画

**导航项目**:
- 首页
- 关于格林
- 家庭成员
- 趣事集锦
- 互动游戏

#### 3.2.6 Game Section - 互动游戏区
**功能**:
- "找出格林"互动游戏
- 展示多张狼的图片
- 用户点击选择
- 答题反馈

**游戏流程**:
```
1. 显示提示文字："这些狼中，哪只是格林？"
2. 展示3-6张狼的图片（网格布局）
3. 用户点击某张图片
4. 显示答案：
   - 正确：显示祝贺信息 + 播放视频/跳转链接
   - 错误：显示提示 + "再试一次"按钮
5. 支持重新开始游戏
```

**布局**:
```
       找出格林小游戏
       ───────────────

┌──────┐  ┌──────┐  ┌──────┐
│ 狼1   │  │ 狼2   │  │ 狼3   │
│      │  │      │  │      │
└──────┘  └──────┘  └──────┘

┌──────┐  ┌──────┐  ┌──────┐
│ 狼4   │  │ 狼5   │  │ 狼6   │
│      │  │      │  │      │
└──────┘  └──────┘  └──────┘
```

**交互效果**:
- 图片悬浮：边框高亮 + 轻微放大
- 点击后：禁用其他图片，显示答案覆盖层
- 答对动画：成功特效（如五彩纸屑、缩放）
- 答错动画：抖动效果

**数据结构**:
```javascript
const gameData = {
  question: "这些狼中，哪只是格林？",
  options: [
    {
      id: 1,
      image: "/assets/game/wolf1.jpg",
      isCorrect: true,
      successMessage: "恭喜你，答对了！",
      videoUrl: "https://bilibili.com/xxx"
    },
    {
      id: 2,
      image: "/assets/game/wolf2.jpg",
      isCorrect: false,
      failMessage: "很遗憾，这不是格林哦~"
    }
  ]
}
```

## 4. 交互效果详细设计

### 4.1 动画效果清单

| 效果类型 | 应用位置 | 动画描述 | 触发方式 |
|---------|---------|---------|---------|
| **渐入动画** | 所有区块 | opacity: 0 → 1, translateY: 50 → 0 | 滚动进入视口 |
| **悬浮放大** | 卡片、图片 | scale: 1 → 1.05 | 鼠标悬浮 |
| **渐变背景** | 按钮、标签 | 背景颜色平滑过渡 | 鼠标悬浮 |
| **阴影加深** | 卡片 | box-shadow增强 | 鼠标悬浮 |
| **视差滚动** | Hero Section背景 | 背景移动速度 < 内容滚动速度 | 页面滚动 |
| **交错动画** | 家庭成员卡片 | 依次渐入（延迟0.1s递增） | 滚动进入视口 |
| **平滑滚动** | 导航点击 | 锚点滚动动画 | 点击导航 |
| **成功特效** | 游戏答对 | 五彩纸屑/缩放动画 | 点击正确答案 |
| **抖动效果** | 游戏答错 | 左右抖动 | 点击错误答案 |

### 4.2 Framer Motion动画示例

**渐入动画（Fade In Up）**:
```javascript
const fadeInUp = {
  hidden: { opacity: 0, y: 50 },
  visible: {
    opacity: 1,
    y: 0,
    transition: { duration: 0.6, ease: "easeOut" }
  }
}
```

**悬浮放大**:
```javascript
const hoverScale = {
  hover: {
    scale: 1.05,
    transition: { duration: 0.3 }
  }
}
```

**交错动画（Stagger）**:
```javascript
const staggerContainer = {
  hidden: { opacity: 0 },
  visible: {
    opacity: 1,
    transition: {
      staggerChildren: 0.1
    }
  }
}
```

## 5. 模块化内容设计

### 5.1 通用卡片组件（Card）

**组件属性**:
```javascript
<Card
  image="/path/to/image.jpg"
  title="标题"
  description="描述文字"
  link="https://example.com"  // 可选：外部链接
  videoUrl="https://bilibili.com/xxx"  // 可选：视频链接
  onClick={handleClick}
/>
```

**点击行为**:
1. 如果有 `videoUrl`：打开视频弹窗
2. 如果有 `link`：跳转到外部链接
3. 如果有 `onClick`：执行自定义函数
4. 否则：无操作

### 5.2 视频弹窗组件（VideoModal）

**功能**:
- 弹出层显示视频播放器
- 支持B站/YouTube嵌入
- 点击背景关闭
- ESC键关闭

**组件设计**:
```javascript
<VideoModal
  isOpen={isModalOpen}
  onClose={handleClose}
  videoUrl="https://bilibili.com/xxx"
  platform="bilibili" // 或 "youtube"
/>
```

### 5.3 图片卡片组件（ImageCard）

**功能**:
- 展示图片 + 标题 + 描述
- 悬浮效果
- 点击跳转/播放视频

**设计**:
```jsx
<ImageCard
  image="/path/to/image.jpg"
  title="标题"
  subtitle="副标题"
  description="描述"
  hoverEffect="zoom" // 或 "gradient"
```

## 7. 性能优化

### 7.1 图片优化
- 使用现代图片格式（WebP）
- 图片懒加载（Lazy Loading）
- 响应式图片（srcset）

### 7.2 代码优化
- 组件懒加载（React.lazy）
- 代码分割（Code Splitting）
- 打包优化（Vite配置）

### 7.3 动画性能
- 使用 `transform` 和 `opacity` 而非 `width`/`height`
- 使用 `will-change` 提示浏览器
- IntersectionObserver监听滚动
