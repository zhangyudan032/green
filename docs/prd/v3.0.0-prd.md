## 1. 项目概述

### 1.1 版本目标
v3.0.0 是对内容架构的重大调整，从功能模块布局改为**时间线叙事结构**，以格林的生命历程为主线，通过5个核心阶段完整呈现格林的传奇故事。

### 1.2 核心变更
| 变更项 | v2.0.0 | v3.0.0 |
|-------|--------|--------|
| 内容组织 | 功能模块（About, Family, Stories, Game） | 时间线叙事（5个生命阶段） |
| 导航结构 | 平面导航（关于、家庭、故事、游戏） | 纵向时间线（阶段1→阶段2→...） |
| 故事展示 | 混合展示，无时间顺序 | 按阶段分组，时间顺序清晰 |
| 视觉风格 | 功能性卡片布局 | 叙事性时间轴布局 |

### 1.3 设计理念
- **叙事性**：以时间为轴，讲述格林从相遇到成为传奇的完整故事
- **沉浸感**：每个阶段有独特的视觉风格和氛围
- **情感共鸣**：通过故事的时间顺序，让用户感受格林的成长历程

## 4. 技术实现

### 4.1 技术栈（保持v2.0.0）

- React 18
- Vite
- Tailwind CSS
- Framer Motion
- React Scroll

### 4.2 新增组件

#### 4.2.1 TimelineNav - 时间线导航
- 显示5个阶段的导航
- 高亮当前阶段
- 平滑滚动跳转

#### 4.2.2 StageSection - 阶段区块
- 接收阶段数据（标题、时间、描述、故事）
- 根据阶段ID应用不同的色调主题
- 渲染故事卡片

#### 4.2.3 StoryCard - 故事卡片
- 展示单个故事
- 支持多种布局（网格、时间轴、沉浸式）
- 图片 + 文字 + 视频

#### 4.2.4 ImmersiveStory - 沉浸式故事
- 专门用于阶段4的单个重点故事
- 全屏滚动叙事
- 大图 + 长文 + 视频组合

#### 4.2.5 SummarySection - 总结区块
- 阶段5专用
- 精美的文字排版
- 引用、数据、图片混合布局
